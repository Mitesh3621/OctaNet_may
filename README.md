## 📌 Project Overview

This project showcases:

* A professional business landing page layout
* A fully functional To-Do list application
* Clean UI design with structured styling
* Interactive JavaScript functionality

The goal was to demonstrate front-end development skills using pure HTML, CSS, and JavaScript without external frameworks.

---

## 🖥️ Landing Page Features

* Responsive navigation bar
* Hero section with background image
* About section
* Services section (Consulting, Strategy, Implementation)
* Contact section with:

  * Social media integration (Instagram, WhatsApp, Facebook, Twitter)
  * Contact form layout
* Hover effects and smooth UI styling
* Structured layout using Flexbox

---

## ✅ To-Do Application Features

* Add new tasks
* Mark tasks as completed
* Edit existing tasks
* Delete tasks
* Clean, minimal user interface
* Dynamic DOM updates using JavaScript

---

## 🛠️ Tech Stack

**Frontend**

* HTML5

**Icons & Styling**

* Font Awesome CDN
